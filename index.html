Parte A — Verdadero o Falso

1. En Kotlin, una variable declarada con val no puede recibir una nueva asignación después de ser inicializada.

2. En Jetpack Compose, TextField utiliza onValueChange para informar que el texto ingresado cambió.

3. Column organiza sus elementos principales horizontalmente.

4. El modificador Modifier.fillMaxWidth() permite que un componente ocupe todo el ancho disponible.

5. El bloque onClick de un Button se ejecuta cuando el usuario presiona el botón.

Parte C — Análisis de código

15. Observá el código:

fun saludar(nombre: String): String {
    return "Hola $nombre"
}

¿Qué devuelve saludar("Ana")?

16. Observá:

val numeros = listOf(10, 20, 30)
val resultado = numeros.filter { it > 15 }

¿Cuál es el contenido de resultado?

17. En este fragmento:

var temperatura by remember { mutableStateOf("") }

TextField(
    value = temperatura,
    onValueChange = { temperatura = it },
    label = { Text("Temperatura") }
)

¿Qué ocurre cuando el usuario escribe en el campo?

18. ¿Qué organización visual representa mejor este código?

Column(
    horizontalAlignment = Alignment.CenterHorizontally
) {
    Text("Temperatura")
    Button(onClick = { }) {
        Text("Calcular")
    }
}

19. Observá esta función de Kotlin. ¿Qué concepto representa correctamente?

fun calcularTotal(precio: Double, cantidad: Int): Double {
    return precio * cantidad
}
